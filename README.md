# Karishma Pun Skincare Website

Static, responsive website based on the supplied flyer.

## Included
- Flyer displayed prominently at the top of the website.
- Responsive layout for desktop and mobile.
- Services and treatment information.
- Request a Quote form.
- Request via WhatsApp using 0452 403 408.
- Request via email using karishmapun21@gmail.com without opening the visitor’s email application.
- Animated success confirmation after a successful email submission.
- Click-to-call phone link.
- WhatsApp uses wa.me. Email submission uses FormSubmit AJAX; the recipient may need to complete FormSubmit’s one-time email activation if it has not already been activated.

## Files
- index.html
- styles.css
- script.js
- assets/SAM.jpeg

## Deploy
This folder can be uploaded directly to Netlify, Vercel, GitHub Pages, or another static web host.
